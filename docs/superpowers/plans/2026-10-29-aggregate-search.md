# 同名影片合卡 / Aggregate search results

**Goal / 目标：** 在保留全源渐进搜索的基础上，按 LibreTV v2.21.1 的片名、年份规则合卡。

**Architecture / 实现：** `AppleCmsParser.aggregate` 提供片名分桶和年份拆分；`MainActivity` 用分组渲染结果，详情默认读取首条已返回资源，其他资源以同页按钮切换。仍沿用现有搜索与详情 API，不改播放器、配置结构或系统。

**Scope / 范围：** 同名翻拍按年份分开；年份未知仅在没有冲突年份时合并。流式追加保留当前选中卡片；点开详情仍沿用现有取消未完成搜索的行为。本次不加入后台目录同步、画质探测或播放中换源。
