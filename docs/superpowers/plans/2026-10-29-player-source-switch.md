# 播放中换源 / In-player source switching

**Goal / 目标：** 在现有播放器内检索其他同片来源，按详情响应耗时排序，保留当前集数、时间和播放／暂停状态。

**Architecture / 实现：** 沿用 Api、Prefs、Media3 实例及已有协程。Main 传入当前来源身份；旧历史按本 App 标题格式还原片名和集数，不迁移存储。查询期间维持原播放，选定后替换列表；首帧确认成功，失败或 15 秒无首帧恢复原列表和断点。缺少当前集则不切换。

**Scope / 范围：** 接口响应耗时不代表视频带宽；跨源剪辑差异无法保证逐帧对齐。不引入双播放器、服务端、系统设置或新运行时。
