# LibreTV 0.1.4：上游首页分类补齐

日期：2026-10-29。应用包名 `local.libretv.standalone.tv`，versionCode 5，显示名称 `LibreTV`。已通过原开发签名覆盖安装到坚果 N5 Pro / K981CN。

## 本次变化

在现有主导航与海报墙之间增加分类栏，标签采用 LibreTV v2.21.1 的 [douban-section.tsx](https://github.com/LibreSpark/LibreTV/blob/v2.21.1/src/components/douban-section.tsx#L11)。沿用原生控件、直连推荐请求、分页、全源搜索和播放器；没有加入服务端或系统服务。

- 电影：热门、最新、经典、豆瓣高分、冷门佳片、华语、欧美、韩国、日本、动画。
- 剧集：热门、美剧、英剧、韩剧、日剧、国产剧、港剧、日本动画、综艺、纪录片。
- 综艺主入口保留。暂不增加截图中的院线、独播、获奖，也未增加未经验证的电影类型标签。

## 操作

1. 主导航选择电影或剧集，向下进入分类栏。
2. 左右移动，OK 选择分类；蓝色底表示选中分类，白框表示遥控焦点。
3. 向下进入海报，海报第一行向上回到当前分类；分类栏向上回主导航。
4. 点海报仍按片名搜索全部启用来源；返回首页保留当前分类。切换分类会从第一页重新请求。

推荐为空或请求失败时保留分类入口，允许切换分类、重试或进入搜索。首页推荐是上游片单，不保证每部影片在用户配置的片源中都有可播资源。
