# LibreTV 0.1.5：同名合卡与详情来源切换

日期：2026-10-29。包名 `local.libretv.standalone.tv`，versionCode 6。已同签名覆盖安装到坚果 N5 Pro / K981CN；原 DpadTV 保留。

## 规则与操作

分组移植自 LibreTV v2.21.1 [video-card.tsx / aggregateResults](https://github.com/LibreSpark/LibreTV/blob/v2.21.1/src/components/video-card.tsx#L45)：

- 按精确片名分组，仅去首尾空白；不同季、电影解说及带不同名称注记的版本保留独立卡片。
- 同名且已知年份冲突时，按年份拆开；未知年份有歧义时单独保留，仅有一个已知年份时合入该组。
- 沿用快结果先显示、慢源继续追加。追加时按原资源找回当前选中卡片。

卡片显示资源数及来源，OK 默认打开第一条已返回资源的详情并聚焦集数。详情页向上进入来源栏，左右选择、OK 切换；返回结果页仍停在原卡片。多个来源时不增加必选来源弹窗。

其他来源可以在第一条资源加载失败后继续选择。详情加载期间返回会取消界面请求，避免返回结果后又被拉进详情。

## 范围

本次新增的是分组和同页来源切换，没有修改播放器、媒体缓存、存储格式或系统设置。运行仍为设备直连片源，无新服务器或 ADB reverse 依赖。

默认资源按已经返回的顺序选取，不额外做画质、网速排序。进入详情沿用原来取消未完成搜索的行为，来源栏展示打开时已经返回的资源。播放中重新检索全源、保留当前集数换源是下一阶段。

本次没有移植上游的画质探测、统一资源备注推断、广告过滤或特殊代理。直播及应用内更新仍不在当前需求内。
