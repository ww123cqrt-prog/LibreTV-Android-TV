- AppleCmsParser.kt is a Kotlin adaptation of LibreTV src/lib/cms-parser.ts, including playback-line selection, metadata parsing and search relevance rules. This derived implementation is offered under AGPL-3.0-or-later. The pinned original file is included for provenance and executable test-fixture generation.
- Native recommendation requests follow the endpoint/query/header mapping in LibreTV src/lib/douban.ts (pinned copy included). Api.kt also adds public Douban image Referer headers on the Android direct transport; it does not implement a proxy.
- Native recommendation category labels follow LibreTV v2.21.1 src/components/douban-section.tsx lines 11-12: https://github.com/LibreSpark/LibreTV/blob/v2.21.1/src/components/douban-section.tsx#L11. Version 0.1.4 adds these existing labels to the Android remote navigation without introducing another catalogue service.
- Search aggregation follows LibreTV v2.21.1 src/components/video-card.tsx aggregateResults: https://github.com/LibreSpark/LibreTV/blob/v2.21.1/src/components/video-card.tsx#L45. Version 0.1.5 ports its exact-title/year grouping to Kotlin; the Android detail page opens the first returned resource by default and offers the others on the same page.
- Version 0.1.6 adds Android in-player source selection using the existing Kotlin Apple CMS transport and title/year matching. It reuses one Media3 player, preserves episode/position/play intent, and restores the previous playlist when a new source fails before its first frame. The generated video fixture and temporary loopback HTTP server are test-APK-only.
- This projector / Android TV adaptation changes application identity and backend integration while retaining DpadTV UI, Media3 playback, cache and history code. It is a community project, not an official DpadTV or LibreTV release.
- Existing DpadTV screenshots, icons, and docs/donate-*.png were inherited from upstream. The donation QR codes belong to the upstream author; they are not donation accounts of this adaptation's maintainer.

Distribute the corresponding complete source together with this combined build and retain both upstream license texts and these notices. Source is published at https://github.com/ww123cqrt-prog/LibreTV-Android-TV. The initial source list contains nine editable third-party API addresses; it does not read configuration from another installed app, and no account credentials are included.
